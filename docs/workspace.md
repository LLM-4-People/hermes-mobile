# Mobile layouts and artifacts

Open a thread’s artifact library to read the code and diffs in its assistant messages. Named fences collect revisions by language and filename. Unnamed excerpts remain separate. The library derives its contents from the loaded transcript, with the most recent assistant messages taking priority within the reader’s memory budget. The original conversation remains on the gateway. HTML and SVG open as selectable source. A deliberate copy places the chosen version in the Android clipboard and marks it as sensitive.

In a coding discussion, ask “Turn this review into a tool I can use again.” The thread menu also provides **Créer un outil pour ce fil**. It stages an editable request alongside any existing draft. A named tool in an assistant reply lets you try the form in that discussion. Pin the tool to return to it later. When Hermes proposes a revision, compare what changed before adopting it. Undo restores the previous choice. Each new request identifies the pinned page to Hermes. Field entries stay on the phone until you transfer them to a message and send it.

Ask Hermes to rearrange a built-in screen, replace its authenticated content, or create a named screen for a task. It can build forms, link workspace pages, show the active conversation title and order the native composer, status and transcript. Open the resulting layout proposal from the thread’s artifact library. The preview names the destination screen and shows the proposed sections. Select **Appliquer la disposition…** and confirm to use it for this profile. The Atelier’s native screen-layout menu provides **Annuler la modification** and **Rétablir**. A change retains its preceding revision for undo. Applying and undoing keep each profile’s layouts in its encrypted account storage.

If a built-in screen’s saved layout cannot be read, choose **Rétablir l’atelier** in the menu, select that screen and confirm **Rétablir**. This discards its unreadable layout history for the unlocked profile and allows a new proposal to be applied.

For damaged named pages, open **Mes écrans** and choose **Réparer la bibliothèque…**. Read the confirmation before selecting **Réparer**. Repair keeps recoverable pages and revisions. If the entire library is unreadable, confirming clears all its named pages and revisions for this profile.

The mobile run includes compact layout instructions. Operators who want the full instructions available to Hermes in other sessions can install the [Hermes Mobile workspace skill](../skills/hermes-mobile-workspace/SKILL.md) in the active profile’s skills directory. Copy the complete `hermes-mobile-workspace` folder there. The skill contains the schema, editing options and working examples. Layout proposals use installed native actions. Changes requiring a new native capability go through the application's source review, build, signing, and update process.

Open **Mes écrans** to reach an installed page. A custom form opens an editable review of the draft it creates. **Vers le brouillon** transfers that text into the native conversation, where **Envoyer** sends it. The native screen-layout menu remains accessible when a custom layout replaces an entire screen. Removing a custom page retains one undo revision. If you choose to erase that removed revision, the library frees the page’s place.
