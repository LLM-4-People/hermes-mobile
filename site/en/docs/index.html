Hermes Mobile documentation

Everything needed to install a verified signed APK, connect your profile to a self-hosted Hermes companion server, and run parallel workflows safely on Android 9–16.

1. Install and keep updated

  • Official signed GitHub Releases: Download Hermes-Mobile.apk, SHA256SUMS, and release.json from the latest release.
  • Verified in-app updates: Open Activity → App updates. The app checks official HTTPS GitHub release hosts, validates constant-time SHA-256 checksums, and confirms a matching signing certificate before handing off to Android’s installer.
sha256sum -c SHA256SUMS adb install -r Hermes-Mobile.apk

2. Single-host multi-profile setup

Hermes Mobile requires our companion server fork (LLM-4-People/hermes-agent). One single HTTPS domain serves multiple isolated users under /p/<profile>—no per-user subdomains required.

  1. Deploy the companion server and run python3 scripts/mobile_doctor.py on the host to verify all 51 active capabilities and print each user’s connection URL.
  2. On Android, open Connect Hermes, enter your profile label, HTTPS host (for example https://hermes.example.com), your Server profile slug, and your 256-bit access key.
  3. Protect the local device vault with a passphrase and optionally enable Class-3 biometrics in Activity → Security.

3. Global command palette and everyday templates

  • Command palette (Ctrl+K / Cmd+K): Open from the top bar or hardware keyboard to jump across all native destinations, recent discussions, and reusable templates using accent-insensitive fuzzy matching inside a FLAG_SECURE dialog.
  • Everyday workflows and custom templates: Open Atelier → Everyday workflows for 6 curated everyday templates plus per-profile encrypted custom templates stored in your local vault. Every template obeys the editable draft rule—staging text in your composer so you review before tapping send.

4. Live connection doctor

Open Activity → Connection doctor to execute 6 parallel non-blocking health checks off the UI thread:

  • Server reachability and latency: Measures round-trip response time and surfaces auth or network errors clearly.
  • Companion fork capabilities (51/51): Distinguishes the full companion fork from plain upstream servers with actionable guidance.
  • Push, updates, ambient, and language sync: Verifies instant notification registration, installed vs latest release status, optional notification listener connectivity, and active language alignment.
  • Copy safe report: Under Technical details, copy a strictly redacted diagnostic summary containing only your sanitized host, app version, language, and check statuses—zero bearer keys, profile names, notes, or messages.

5. Concurrent tasks and runtime performance

  • True multi-run per user: Start a long coding or research task in Thread A, switch to Thread B and Thread C to launch additional runs, and return to Thread A without losing live streams or mixing deltas/approvals. Android 16 live updates display your active task count with per-run stop support.
  • Instant infinite chats: Switching discussions renders immediately and loads older history smoothly on demand.
  • Lean resource footprint: Frame-budgeted stream coalescing (0 ms first-token latency), zero-allocation custom views, bounded bitmap and highlight caches cleared on memory pressure or lock, and an R8-shrunk ~1.9 MiB signed release APK.

6. Brain studio and universal same-server sharing

Open the Brain tab to edit Hermes memory (MEMORY.md / USER.md), manage smart notes, review pattern-gated habit suggestions (>= 3 occurrences), run full-text FTS5 history searches, manage skills, and browse workspace files and Git diffs.

Share 7 resource kinds—notes, skills, custom surfaces, widgets, tools, artifacts, and threads—selectively with other profiles on the same server without exposing your private workspace.

7. Live UI modding and home screen widgets

Ask Hermes to adapt a built-in screen, adjust day/night theme accents (WCAG-AA 4.5:1 contrast enforced), or author an interactive tool with preview, atomic apply, and full revision rollback. Pin profile-scoped widgets directly to your Android home screen—cross-profile taps stay locked behind profile authentication.

8. Security, ambient privacy, and zero-leak push

  • Profile vault hardening: Per-profile AES-GCM encryption, persisted passphrase backoff, atomic profile wipe, and session-epoch fencing on every async callback.
  • Zero-root ambient intelligence: Completely OFF by default per profile. A fail-closed privacy filter hard-blocks OTP/2FA codes, password managers, banking apps, and secret lockscreen notices before content enters memory.
  • Zero-leak closed-app push: Firebase Cloud Messaging or self-hosted UnifiedPush (ntfy + RFC 8291 Web Push) transmit opaque routing metadata only—messages remain on your server until unlock.
