Hermes Mobile documentation

Install a verified signed APK, pair your phone with a self-hosted Hermes companion server, and run parallel workflows safely on Android 9 to 16.

1. Install and keep updated

  • Official signed GitHub Releases: Download hermes-mobile-v0.2.1.apk, SHA256SUMS, and release.json from the latest release.
  • Verified in-app updates: Open Settings > App updates. The app checks official HTTPS GitHub release hosts, validates constant-time SHA-256 checksums, and confirms a matching signing certificate before launching Android’s installer.
sha256sum -c SHA256SUMS adb install -r hermes-mobile-v0.2.1.apk

2. QR pairing and single-host multi-profile setup

Hermes Mobile connects to the companion server at LLM-4-People/hermes-agent. One single HTTPS host serves isolated users under /p/<profile> with no per-user subdomains required.

  1. Deploy the companion server and run python3 scripts/mobile_setup.py --invite alex --qr on the host to create an isolated profile and a single-use 5-minute pairing ticket.
  2. On Android, open Connect Hermes and tap Paste pairing link or open the hermes://pair deep link. Confirm the target host before claiming, or fill in host, profile slug, and access key manually.
  3. The first profile acts as admin with an in-app Admin console for inviting members, rotating keys, setting concurrency caps, and revoking active tickets.
  4. Protect the local device vault with your choice of Biometrics / device lock, a 6 to 12 digit PIN, or a 12+ character passphrase (with a smart 5-minute default auto-lock grace, configurable in Settings > Security) and manage optional Android capabilities in Settings > Permissions.

3. Universal search, command palette, and everyday templates

  • Universal search on every screen: Tap Search in the top bar from any workspace to search chats (with server FTS5 snippets), smart notes, shared items, settings, and tools in one FLAG_SECURE overlay, or press Ctrl+K / Cmd+K on a hardware keyboard for the command palette.
  • Everyday workflows and custom templates: Open Apps > Everyday workflows (or launch quick templates directly from an empty chat) for 6 built-in workflows plus encrypted per-profile custom templates. Every template obeys the editable draft rule and stages text in the composer until you tap Send.

4. Live connection doctor

Open Settings > Connection doctor to execute 6 parallel non-blocking health checks off the UI thread:

  • Server reachability and latency: Measures round-trip response time and surfaces auth or network errors clearly.
  • Companion capabilities (51/51): Distinguishes the full companion fork from plain upstream servers with actionable next steps.
  • Push, updates, ambient, and language sync: Verifies instant notification registration, installed vs latest release status, optional notification listener status, and language alignment.
  • Copy safe report: Under Technical details, copy a redacted diagnostic summary containing only sanitized host, app version, language, and check statuses with zero keys, profile names, or messages.

5. Concurrent tasks and runtime performance

  • True multi-run per user: Start a coding or research task in one discussion, switch to another thread to launch an additional run, and return without losing live streams or mixing deltas and approvals.
  • Instant infinite chats: Switching discussions renders immediately and loads older history smoothly on demand.
  • Lean resource footprint: Frame-budgeted stream coalescing, zero-allocation custom views, bounded bitmap caches cleared on memory pressure or lock, and an R8-shrunk ~1.9 MiB signed release APK.

6. Notes, inline sharing, and power tools

Switch cleanly between Discussions (with inline All · Pinned · Shared filters), Notes & Tasks (live Notes with My notes · Shared with me filters, Reminders, and Inbox), and Apps (Hands-free Voice, Custom Screens, and Templates). Power tools (Hermes memory MEMORY.md and USER.md, skills, workspace files, Git diffs, and Appearance Studio) live inside the top-bar Settings Hub.

Share 7 resource kinds (notes, skills, custom surfaces, widgets, tools, artifacts, and threads) selectively with other profiles on the same server without exposing your private workspace.

7. Live UI modding and home screen widgets

Tune theme mode, palette, density, and shortcuts in Settings > Appearance, or ask Hermes to adapt a built-in screen, adjust day and night theme accents with WCAG-AA 4.5:1 contrast enforced, or author an interactive tool with preview, atomic apply, and full revision rollback. Pin profile-scoped widgets directly to your Android home screen while keeping cross-profile taps locked behind profile authentication.

8. Security, Landlock isolation, and zero-leak push

  • Profile vault hardening and multi-mode lock: Per-profile Android Keystore AES-256-GCM encryption, Biometrics / 6 to 12 digit PIN / 12+ character passphrase lock modes, smart 5-minute default auto-lock grace (configurable), persisted backoff, FLAG_SECURE overlays, atomic profile wipe, and session-epoch fencing on async callbacks.
  • Permissions center (Settings > Permissions): Inspect every optional Android permission (notifications, microphone, camera, approximate location, calendar, notification access, package installs) with 1-tap Allow or Open Android settings actions and zero silent prompts.
  • Server kernel isolation: On the companion server, Linux kernel Landlock LSM physically blocks subprocesses from reading sibling profile directories (EACCES), while non-admin profiles exclude terminal and code_execution by default.
  • Ambient privacy off by default: Optional context signals start completely disabled per profile, with a fail-closed privacy filter blocking OTP codes, password managers, banking apps, and lockscreen secrets before content enters memory.
  • Zero-leak closed-app push: Firebase Cloud Messaging or self-hosted UnifiedPush (ntfy + RFC 8291 Web Push) carry opaque routing metadata only so messages stay on your server until unlock.

9. Build and verify locally

python3 scripts/fast_check.py ./gradlew :app:lintDebug :app:testDebugUnitTest :app:assembleDebug :app:assembleRelease ./gradlew :app:connectedDebugAndroidTest
