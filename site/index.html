Démarrage rapide

Prêt en 2 étapes

Compilez ou téléchargez l’APK Android (API 28–36), puis provisionnez un ou plusieurs profils sur un unique serveur HTTPS.

Étape 1 · Android

Installer l’APK signé & mises à jour GitHub intégrées

Téléchargez le dernier APK signé depuis GitHub Releases (l’application vérifie ensuite les nouvelles versions et leur empreinte SHA-256 directement depuis GitHub avant d’ouvrir l’installeur Android), ou compilez localement avec JDK 21 et Android SDK 36.

git clone https://github.com/LLM-4-People/hermes-mobile.git
cd hermes-mobile
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
Télécharger l’APK (Dernière version)
Étape 2 · Serveur unique

Déployer les profils sur un seul hôte HTTPS

Construisez l’image depuis la révision épinglée du fork LLM-4-People/hermes-agent puis générez la pile Docker + Caddy.

python3 deploy/accounts.py "$HOME/.local/share/hermes-deploy" \
  --image "$image" \
  --host hermes.example.com \
  --profile alice --profile bob --push alice
docker compose -f "$HOME/.local/share/hermes-deploy/compose.json" up -d --build
